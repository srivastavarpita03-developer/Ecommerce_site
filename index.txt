Backend Folder structure:
backend
|
src-----|
        server.js(Main Entry Point of backend)
        routes(folder that will contain all routes files)
        controllers(folder that will contain handler functions)
        models(folder that will contain all DB models/tables)
        config(folder that will contain all configuration files)

.env(file that conatins all environment variables),it contains variables which
 we cannot share to other users

 Backend Libraries:
 mongoose (For dealing with database)
 express (for making server)
 dotenv (for accessing variables of .env file)
 cors (for allowing backend to accept request from out frontend)
nodemon (for restaring server whenever code changes)
bcrypt:(for password hashing) 
jsonwebtoken(for generating token)
cookie-parser(for handling cookies related  work)

command:
    npm i express mongoose cors dotenv nodemon  jsonwebtoken cookie-parser multer
